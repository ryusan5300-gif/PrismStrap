FEATURES

ゲームプレイを別次元へ引き上げる機能群

必要なすべての最適化を、ひとつの直感的で洗練されたアプリに凝縮。

⚡

FPS 上限解除 (Unlocker)

Robloxの標準60FPS制限を完全解除。120/144/240FPSや無制限に対応し、高リフレッシュレートモニターの性能を100%発揮します。

DFIntTaskSchedulerTargetFps
🔊

カスタム死亡時サウンド

伝説の元祖「OOF」音、迫力の「Vine Boom」、お好みの「カスタムMP3」を自由に設定。再生音量やピッチ連動速度も自在に調整可能。

FMOD OggS Header Sync
🎨

グラフィック & レンダリング

Direct3D 11 や Vulkan をワンクリック選択。高解像度テクスチャの強制適用や不要なポストエフェクトの削減で軽快な描画を実現。

Vulkan & Direct3D 11
🛠️

ビジュアル FastFlags エディター

危険で面倒な JSON 手動編集は不要。安全な GUI からフラグの追加・変更・削除をリアルタイムに行えます。

ClientAppSettings.json
🚀

洗練されたロードUI & モード選択

ブラウザからの起動時も美しいスプラッシュダイアログを表示。起動時に「Robloxをプレイ」か「設定を開く」かを素早く選べます。

roblox-player:// Protocol
🛡️

100% C# .NET 8 WPF ネイティブ

HTML/WebView2/ブラウザ依存を一切排除。純粋なネイティブコードでビルドされ、極めて軽量かつ超高速に応答します。

No WebView2 Required
